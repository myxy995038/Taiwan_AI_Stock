# Taiwan AI Stock System

## V10 Ultimate Enterprise

Taiwan AI Stock System is an enterprise-grade AI quantitative stock selection platform designed for the Taiwan stock market.

The project integrates quantitative analysis, AI learning, portfolio management, risk control, automated reporting, and closed-loop optimization into a single unified framework.

---

- AI Score Engine
- AI Learning Engine
- AI Dashboard
- AI Executive Summary
- AI Portfolio Manager
- AI Risk Monitor
- AI Performance Monitor
- AI Watchlist Center
- Excel Reporting Engine

# Installation

Create Virtual Environment

```bash
python -m venv .venv
```

Activate

```bash
.\.venv\Scripts\Activate.ps1
```

Install Packages

```bash
pip install -r requirements.txt
```
